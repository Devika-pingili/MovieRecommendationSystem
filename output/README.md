# Output

This folder contains the output generated by the Hadoop MapReduce jobs.

## Job 1 – Movie Rating Analysis

**Job:** `MovieRatingAnalysis`

**Input:** `ratings.csv`

**Output:** Movie-wise rating count and rating sum.

### Output Columns

| Column    | Description                                   |
| --------- | --------------------------------------------- |
| `movieId` | Unique ID of the movie                        |
| `count`   | Total number of ratings received by the movie |
| `sum`     | Sum of all ratings received by the movie      |

### Sample Output

| movieId | count |      sum |
| ------: | ----: | -------: |
|       1 | 68997 | 269088.3 |
|       2 | 29449 |  94900.2 |
|       3 | 13134 |  41259.0 |
|       4 |  1283 |   3655.0 |
|       5 |  3318 |  10162.0 |

---

## Job 2 – Movie Rating Statistics

**Job:** `MovieRatingStatistics`

**Input:** Output generated by `MovieRatingAnalysis`

**Output:** Movies satisfying the minimum rating conditions with their average rating.

### Conditions Applied

| Condition                 | Value |
| ------------------------- | ----: |
| Minimum number of ratings |   100 |
| Minimum average rating    |   4.0 |

### Output Columns

| Column          | Description                 |
| --------------- | --------------------------- |
| `movieId`       | Unique ID of the movie      |
| `count`         | Total number of ratings     |
| `averageRating` | Average rating of the movie |

### Sample Output

| movieId | count | averageRating |
| ------: | ----: | ------------: |
|       1 | 68997 |          3.90 |
|      10 | 32474 |          3.43 |

---

## Output Files

When the Hadoop jobs are executed, Hadoop generates output files such as:

```text
part-r-00000
```

The output directories are:

```text
output_analysis/
└── part-r-00000

output_stats/
└── part-r-00000
```

### Job 1

```text
movieId    count    sum
```

### Job 2

```text
movieId    count    averageRating
```

---

## Output Summary

| Job                     | Input         | Output                              |
| ----------------------- | ------------- | ----------------------------------- |
| `MovieRatingAnalysis`   | `ratings.csv` | `movieId`, `count`, `sum`           |
| `MovieRatingStatistics` | Job 1 output  | `movieId`, `count`, `averageRating` |

> **Note:** The current implementation outputs `movieId` rather than movie titles because `movies.csv` is not joined with the rating data.
