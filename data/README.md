# Dataset

This project uses the **MovieLens 32M dataset** provided by GroupLens.

## Download Dataset

Download the MovieLens 32M dataset from the official website:

[MovieLens 32M Dataset – GroupLens](https://grouplens.org/datasets/movielens/32m/?utm_source=chatgpt.com)

Download and extract the dataset. It contains:

```text
ml-32m/
├── links.csv
├── movies.csv
├── ratings.csv
└── tags.csv
```

### `ratings.csv`

The `ratings.csv` file is approximately **800+ MB**, so it is not included in this GitHub repository.

After downloading the dataset, copy `ratings.csv` into this project's `data/` folder:

```text
data/
├── links.csv
├── movies.csv
├── ratings.csv
└── tags.csv
```

The four MovieLens CSV files contain the following columns:

### ratings.csv

```text
userId, movieId, rating, timestamp
```

### movies.csv

```text
movieId, title, genres
```

### tags.csv

```text
userId, movieId, tag, timestamp
```

### links.csv

```text
movieId, imdbId, tmdbId
```

# Columns Used in This Project

The MapReduce analysis uses **only two columns from `ratings.csv`**:

| Column    | Purpose                  |
| --------- | ------------------------ |
| `movieId` | Identifies the movie     |
| `rating`  | Rating given by the user |

The following columns are not used in the MapReduce calculation:

* `userId`
* `timestamp`

The `movies.csv`, `tags.csv`, and `links.csv` files are kept in the repository as dataset reference files. They are not used by the current two MapReduce jobs.

# Job 1 – MovieRatingAnalysis

### Input

```text
ratings.csv
```

Relevant columns:

```text
movieId, rating
```

### Mapper

The mapper reads each rating record and extracts:

```text
movieId
rating
```

It produces:

```text
movieId → rating
```

Example:

```text
1 → 4.0
1 → 5.0
1 → 3.0
2 → 3.5
```

### Reducer

The reducer groups all ratings belonging to the same `movieId`.

It calculates:

* Number of ratings
* Sum of ratings

### Job 1 Output

```text
movieId    count    sum
```

Example:

```text
1    68997    269088.3
2    29449    94900.2
```

So, Job 1 transforms:

```text
movieId + rating
        ↓
movieId + count + sum
```

---

# Job 2 – MovieRatingStatistics

Job 2 uses the output generated by Job 1.

### Input

```text
movieId    count    sum
```

### Mapper

The mapper reads:

```text
movieId
count
sum
```

It calculates the average rating:

```text
average = sum / count
```

It then applies the project conditions:

```text
count >= 100
average >= 4.0
```

Only movies satisfying both conditions are passed to the reducer.

### Reducer

The reducer receives the filtered movie records and writes them to the final output.

### Job 2 Output

```text
movieId    count    averageRating
```

Example:

```text
1    68997    3.90
10   32474    3.43
```

So, Job 2 transforms:

```text
movieId + count + sum
        ↓
average = sum / count
        ↓
filter:
count >= 100
average >= 4.0
        ↓
movieId + count + averageRating
```

# Complete Data Flow

```text
ratings.csv
     │
     │  movieId + rating
     ▼
┌──────────────────────┐
│ MovieRatingAnalysis  │
│       Job 1          │
└──────────────────────┘
     │
     │ movieId + count + sum
     ▼
┌──────────────────────┐
│ MovieRatingStatistics│
│       Job 2          │
└──────────────────────┘
     │
     │ movieId + count + averageRating
     ▼
 Final Output
```

### Summary

| Stage         | Input Columns                       | Processing                     | Output Columns                      |
| ------------- | ----------------------------------- | ------------------------------ | ----------------------------------- |
| Job 1 Mapper  | `movieId`, `rating`                 | Groups ratings by movie        | `movieId → rating`                  |
| Job 1 Reducer | `movieId`, `rating`                 | Calculates count and sum       | `movieId`, `count`, `sum`           |
| Job 2 Mapper  | `movieId`, `count`, `sum`           | Calculates average and filters | `movieId`, `count`, `averageRating` |
| Job 2 Reducer | `movieId`, `count`, `averageRating` | Writes final results           | `movieId`, `count`, `averageRating` |

**Note:** Movie titles are not included in the current output because `movies.csv` is not joined with the rating data.
